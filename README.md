This repository contains various Jupyter Notebooks and scripts dedicated to Exploratory Data Analysis (EDA). It demonstrates my ability to take raw, unstructured data and extract meaningful statistical insights and visualizations.

## Overview
- **Objective:** To uncover hidden patterns, detect anomalies, test hypotheses, and check assumptions with the help of summary statistics and graphical representations.
- **Approach:** Comprehensive data cleaning, missing value handling, univariate and bivariate analysis, and correlation mapping.

## Tech Stack
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn, Plotly
